# Student Management System

A menu-driven console application in Core Java for managing student records.

## Features
- Add a new student
- View all students
- Search for a student
- Update student details
- Delete a student
- Input validation and exception handling for reliable use
- Student data saved to a text file (students.txt) using Java I/O

## Concepts Used
- Object-Oriented Programming: classes, objects, constructors, encapsulation
- Collections: ArrayList and Iterator
- Exception handling
- Java I/O
- Menu-driven flow using loops and switch-case

## Project Structure
- `Main.java`: program entry point and menu
- `Student.java`: student model class
- `StudentManager.java`: logic for add, view, search, update, delete

## How to Run
1. Install JDK 8 or higher
2. Compile: `javac Main.java Student.java StudentManager.java`
3. Run: `java Main`
